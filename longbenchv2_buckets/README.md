## 选样说明

- 长度用 `Qwen/Qwen3.8-27B` tokenizer 计算；
- 36k 组限定在 32,768–49,152，32k 组限定在 <32,768，64k 组限定在 ≥49,152，保证四组互不重复；
- 每组内按距离目标最近取 42 条；
- **没有截断**，`context` 是原始全文；
- 由于原始分布稀疏（32k–49k 区间只有 44 条），`32k_42` 与 `36k_42` 的实际范围会比目标宽，这是不截断的必然结果。
