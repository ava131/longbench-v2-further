# TV Assistant 数据集

家庭电视智能助手的多轮中文对话，每条约 32k tokens。

## 话题来源

`topics.json` 来自真实电视助手日志：17 类话题、113 条真实用户 query（美国队长、动画片、比利时、养生、提醒吃药、天气、播放歌曲、科普问答、健康、视频、新闻、电视剧、换台、电影、回放、学习、听书）。

## 生成方式

- 每条对话只选 **1 个主话题**，允许自然联想（如美国队长 → 吴京、战狼），但不切换到天气/股票等无关话题；
- 用 `collect_tv.py` 逐段续写，累计到 32,768（允许 +1,000）；
- 模型默认 `deepseek-flash`，可通过 `BASE_URL` / `MODEL` 换成 vLLM 上的 qwen；
- 对话格式为 `user: ...` / `assistant: ...`。

## 数据集

| 目录 | 内容 |
|---|---|
| `32k_40/` | 40 条独立对话（32,957 – 33,768 tokens） |
| `32k_218/` | 按 PersonaMem-218 排布生成的 218 条：20 base ×10、14 独立、2 首尾复制、5 对离群间隔 0/1/50/100/200 |

`32k_218` 复用了 `schedule_218.json` 里原 218 数据集的精确位置与 `kind`，因此间隔分布完全一致（均值 22.55、中位 22，离群 0/1/50/100/200 各一条）。

## 脚本

| 文件 | 用途 |
|---|---|
| `collect_tv.py` | 采集/生成对话 |
| `assemble.py` | raw → jsonl |
| `build_218.py` | 按 218 排布映射 |
| `schedule_218.json` | 218 的位置/类型/占用 |
| `topics.json` | 真实话题与 query |

## 注意

- 这是缓存/长上下文性能测试数据，`answer`、选项为空占位；
- 对话由模型生成，剧名、天气、股价等数字不保证实时准确；
- token 数用 Qwen tokenizer 统计，不含 system prompt 与 chat template。
